# StockForge - Public Marketing & Product Website

Official public website for StockForge Offline Desktop POS and Inventory Management.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4 + Framer Motion
- **Icons:** Lucide React
- **Routing:** React Router v7

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Type check & build for production:
   ```bash
   npm run lint
   npm run build
   ```
